## Your Task

Examine the chart image carefully and locate the following:

1. **Key data points**: peaks, valleys, endpoints, inflection points, trend changes
2. **Task-relevant points**: specific data points needed to answer the question above
3. **Reference points**: any labeled or annotated values visible on the chart

For each point, provide:
- `pixel_x`: the horizontal pixel position in the image (use the tick mark positions above as reference anchors)
- `pixel_y`: the vertical pixel position in the image (use the tick mark positions above as reference anchors)
- `role`: what this point represents (peak, valley, start, end, latest, baseline, etc.)
- `description`: brief semantic description of what you see at this location
- `visual_confidence`: how certain you are about the pixel position (high / medium / low)
- `estimated_value`: your rough estimate of the value (the system will compute precisely)

Also provide semantic observations about the chart's overall structure and trends.

## Important Instructions

- The tick mark pixel positions listed above are your REFERENCE ANCHORS — use them to triangulate other positions
- The system will convert your pixel coordinates to precise numerical values via the ruler
- Focus on ACCURATE PIXEL POSITIONING, not on estimating values
- If a data point falls between two tick marks, carefully estimate its pixel position relative to those marks
- Only report points you can clearly see in the chart — do not hallucinate
